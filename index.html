Learn deep learning by running it.

Eight notebooks, from a first classifier to transfer learning. Each one opens in Kaggle or Google Colab and runs on a free cloud GPU, so there is nothing to install on your laptop.

Choose where to run

Recommended for the course. You get a fixed weekly GPU allowance of about 30 hours, and saved versions keep your outputs.

  1. Sign up at kaggle.com. Your university email is fine.
  2. Verify your phone number in your Kaggle account settings. Kaggle only lets verified accounts use a GPU or the Internet.
  3. Open lab 0 below. In the notebook's right-hand panel, set Accelerator to GPU T4 x2 and switch Internet on.

The quickest start: just a Google account, no phone verification. GPU time depends on demand and can run out during busy hours.

  1. Sign in with any Google account.
  2. Open lab 0 below and choose Runtime → Change runtime type → T4 GPU.
  3. Before you close the tab, choose File → Save a copy in Drive, or your changes are lost.

Labs

Do them in order the first time. Each one ends with short exercises. Select a title to see what it covers and preview the code.

    When something goes wrong

    The notebook says the dataset did not download
    On Kaggle, Internet is switched off for that notebook. Turn it on under Settings in the right-hand panel and run the cell again. Kaggle only allows this for phone-verified accounts.
    I can't choose a GPU
    On Kaggle, verify your phone number, or wait for your weekly quota to reset. On Colab, try again later. Labs 0 and 1 don't need a GPU, and the MNIST labs also run on a CPU, just more slowly.
    Opening a lab shows an error
    Sign in to Kaggle or Google in the same browser first, then open the lab again. If it still fails, download the notebook and upload it yourself: on Kaggle use File → Import Notebook; on Colab use File → Upload notebook.
    My session stopped and my variables are gone
    Idle sessions shut down on both platforms. Your code is safe if you saved it, so run all the cells again. Anything you want to keep, such as a trained model, has to be saved as a file and downloaded.
    How do I hand in my work?
    On Kaggle, use Save Version → Save & Run All, then share the notebook with your instructor or download the .ipynb file. On Colab, use File → Download → Download .ipynb. Submit it the way your instructor asks.

    For instructors

    The site has no server. Lessons and notebooks live in a GitHub repository, and every student runs them in their own free Kaggle or Colab account. To add a lab, put the notebook in notebooks/ and add one entry to assets/labs.js; its row and buttons appear automatically.

    For the steadiest experience on Kaggle, publish each lab there yourself with the GPU on and any datasets attached, then paste its address into kaggleUrl. Students then get Kaggle's Copy & Edit, and the settings come with every copy. For graded challenges with a leaderboard, Kaggle Community Competitions are free to host.
