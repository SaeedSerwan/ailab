How it works

This site hosts the lessons and notebooks. Kaggle runs them. Each student uses their own free Kaggle account, so the university pays nothing for compute and there are no servers to maintain.

Before your first lab

About 5 minutes, once per semester.

  1. Create a Kaggle accountSign up at kaggle.com. Your university email is fine.
  2. Verify your phone numberProfile → Settings → Phone verification. This is required for GPUs and Internet access. One number per account.
  3. Open Lab 00Click Open in Kaggle on the first card below, then click Run All.
  4. Turn on GPU & InternetIn the notebook's right panel: Settings → Accelerator → GPU T4 x2 and Settings → Internet → On.
  5. Check the outputLab 00 should print a Tesla GPU and Internet: ON ✅. You're ready.

Help

The problems students hit most often.

"Open in Kaggle" asks me to sign in, or shows an error

Sign in to Kaggle first in the same browser, then click the button again. If the import still fails, use .ipynb to download the notebook, then on Kaggle choose Create → New Notebook → File → Import Notebook and upload it.

The GPU option is greyed out

Your phone number isn't verified yet, or your weekly GPU quota is used up. The quota resets weekly. Labs 00 and 01 run fine on CPU, and the MNIST labs also work on CPU, just more slowly.

"Could not download the dataset"

Internet is off for that notebook. Open Settings → Internet → On in the right panel and re-run the cell. Kaggle only allows this for phone-verified accounts.

My session stopped and I lost my variables

Sessions stop after inactivity. Your code is kept as long as you saved a version; just Run All again. Anything you need later (models, CSVs) should be written to /kaggle/working.

How do I submit my work?

Click Save Version → Save & Run All so outputs are stored. Then either Share the notebook with your instructor's Kaggle username or download it with File → Download Notebook and upload the .ipynb to the LMS, as your instructor specifies.

Instructors: adding a new lab
  1. Put the notebook in notebooks/ (start it with the same Setup and Loader cells so it works on Kaggle).
  2. Add one entry to assets/labs.js. The card and its buttons are generated automatically.
  3. Optional, most reliable: upload the notebook to Kaggle yourself, attach any datasets, set the accelerator, make it public, and paste its URL into kaggleUrl. The button then becomes Copy & Edit on Kaggle, and the GPU setting and data travel with every copy.
  4. For graded challenges with a leaderboard, host a free Kaggle Community Competition and link it from a lab.
